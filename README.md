# Todo Reminder

A React todo reminder tool built with Vite.

## Features

- Create tasks with notes, reminder time, and priority
- Filter active, overdue, and completed tasks
- Search by task title or note
- Save tasks in browser local storage
- Request browser notifications for due reminders

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
