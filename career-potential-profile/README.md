# 大学生职业潜能画像

这是一个面向大学生的职业发展自测网页，用于输出 7 个维度的个人发展画像：职业兴趣、学习敏捷、问题解决、执行自律、沟通协作、抗压适应、职业价值观。

## 在线查看

如果仓库已经开启 GitHub Pages，可以访问：

https://cxm07.github.io/one/career-potential-profile/

如果还没有开启，请在仓库中进入 `Settings -> Pages`，选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/root`。

## 功能

- 56 题自测。
- 浏览器本地计分，不设置账号，不上传或保存用户数据。
- 输出雷达图、7 个维度分数、Top 3 优势、2 个优先提升方向和 30 天行动计划。
- 支持复制摘要、导出图片、浏览器打印导出 PDF。

## 使用边界

本工具仅用于个人自我探索和职业发展参考，不能替代心理咨询、职业咨询或招聘录用决策。第一版不建立常模，不展示同龄排名。
